# API guide

Base path `/api/v1/`. The machine-readable contract is the OpenAPI schema at `/api/schema/` (63 operations, generated by drf-spectacular and checked in CI with `--fail-on-warn`). This page covers the conventions the schema cannot express.

## Conventions
- **Errors:** `{"error": {"code", "message", "details"}}`. Field errors are in `details`; for a single message `details` is `null`. Some newer staff/moderation endpoints return `{"detail": "..."}` for business-rule failures with the appropriate 4xx status.
- **Auth:** session cookie. Call `GET /auth/csrf/` for a token and send it as `X-CSRFToken` on every write. The web app does this through the same-origin `/api/v1` rewrite, so there is no CORS in normal use. The token rotates on login/logout.
- **Pagination:** list endpoints that return `{count, next, previous, results}` use page numbers (25 per page); most browse endpoints return plain arrays (capped).
- **Throttling:** anon 120/min, user 600/min, login/register 10/min per IP, submissions 20/hour, assistant 20/hour. `429` on excess.
- **Trailing slashes:** Django routes end with `/`; the web proxy adds it, so browser code omits it.
- **Visibility:** every public endpoint returns reviewed records only (plus development data when `SHOW_DEVELOPMENT_DATA` is on, clearly labelled). Staff endpoints (`/staff/...`) check roles server-side.

## Endpoint families
| Family | Examples | Access |
|---|---|---|
| Reference | `generics/`, `generics/<slug>/`, `products/<slug>/`, `companies/<slug>/`, `species/`, `species/<slug>/`, `drug-classes/`, `countries/`, `countries/<iso2>/`, `search/` | public |
| Calculators | `calculators/<name>/` (11 whitelisted pure functions) | public |
| Interactions and assistant | `interactions/check/?generics=a,b`, `assistant/ask/` | check public; ask needs login |
| Prices | `products/<slug>/prices/` (history, current, analytics), `products/<slug>/packs/`, `prices/submissions/` | read public; submit needs login |
| Study | `study/subjects|questions|past-papers|flashcards|lessons|books/`, `study/exams/...`, `study/progress/`, bookmarks and reports | mostly public read; exams, flashcard reviews, progress need login |
| Opportunities | `listings/<jobs|scholarships>/`, `.../<id>/`, `.../submit/`, `.../<id>/report/` | read public; submit/report need login |
| Auth | `auth/csrf|register|login|logout|me/` | as named |
| Staff | `staff/summary|review-queue|price-submissions|question-reports|listings|imports|automation|audit-log/...` | role-gated (editor/reviewer/moderator/admin; audit log and manual runs admin only) |
| Scheduler | `cron/<link-check|feeds>/` | `Bearer CRON_SECRET` only |
| Health | `health/` | public |

## Calculator API
`POST calculators/<name>/` with the function's arguments as JSON; the response has `formula`, `values` (exact decimal strings), `steps` and `warnings`. Results are identical to the browser engine (shared test vectors in `shared/calc-vectors.json`).

## Stability
Pre-1.0: paths and shapes may change between phases. The OpenAPI operation ids are `<app>_<view>` and stable enough for client generation, but treat them as unversioned until a `v2` policy exists.
